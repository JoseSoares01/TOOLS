03

Valores pretendidos

Os totais que devem aparecer no SAP no fim do ajuste.

O total com IVA é sugerido automaticamente pelo IVA calculado por subtotal de taxa. Podes alterá-lo para o valor exato da fatura.

Subtotais por taxa de IVA

Podes proteger os valores por taxa, mesmo que as linhas sejam redistribuídas.

✂ Fatura com uma única linha

Quando só existe uma linha, podemos dividi-la em duas parcelas próximas de 50% e redistribuir os cêntimos para acertar o IVA, preservando a base e a taxa. Para aplicar, é necessário criar a segunda linha no SAP.

Definições avançadas ⌄

Começa por ajustes pequenos. Aumenta apenas se não existir uma solução. Alterações maiores exigidas pelos subtotais são consideradas automaticamente.

✦ Prioridade: menos linhas alteradas → menos cêntimos movidos → menor alteração percentual. Com uma única linha, pode criar duas parcelas.
